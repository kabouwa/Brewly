# Brewly ☕

Brewly is a coffee shop ordering and management application built as a full-stack learning project. It provides a customer-facing interface for browsing products and placing orders, alongside an administration interface for managing the coffee shop.

The project is being developed to practice building a REST API with Laravel and consuming it from a React frontend.

## Tech Stack

### Backend
- **Laravel** — REST API
- **MySQL** — Database
- **PHP** — Backend development

### Frontend
- **React** — User interface
- **Vite** — Development server and build tool
- **JavaScript (JSX)** — Application logic
- **Tailwind CSS** — Styling

## Planned Features

### Customer Interface
- Browse coffee shop products and categories
- Add products to a shopping cart
- Update quantities and remove products
- Place orders without creating an account
- View order confirmation

### Administration
- Administrator authentication
- Manage products and categories
- View orders and order details
- Update order statuses
- View basic order statistics
